# Gatewave v0.2.1

Gatewave 0.2.1 面向高 RTT 系统 VPN 路径优化 TCP/UDP 数据面，重点减少应用自身增加的 Selector 停顿、缓冲分配和重复解析。

## 主要变化

- 极速模式请求 8 MiB 上游 TCP 接收窗口和 2 MiB 发送窗口。
- TCP Relay 在一次就绪事件内读后直写，并用 512 KiB 事件预算兼顾吞吐与多会话公平。
- 极速模式 DirectBuffer 可自适应增长到 128 KiB，每条 TCP lane 最多复用 8 MiB 空闲缓冲。
- 增加 TCP 当前/峰值排队、直写量、背压、公平让出、缓冲复用和分配计数。
- 保留 SOCKS 握手后已预读的首批业务数据，确保完整交接给 TCP Relay。
- UDP 增加字面量地址和目标端点缓存快路径，降低 QUIC/UDP 热路径开销。
- 网络诊断增加 VPN RTT、单流与 4 流下载结果，并识别高延迟单流受限。

## 验证摘要

- Pixel 10a、极速模式、同一公网测试窗口：5 MiB 单流 4.82 → 5.36 Mbps，4 流聚合 14.85 → 19.53 Mbps。
- 16 路并发 1 MiB 下载全部返回 HTTP 200，聚合 15.66 Mbps。
- 压测完成后 TCP 排队回到 0，未记录 Relay 崩溃或异常退出。

公网链路会随 VPN 网关和服务端状态波动，以上数字用于回归对照，不代表固定带宽承诺。
