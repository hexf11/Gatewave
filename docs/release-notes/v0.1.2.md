Gatewave 0.1.2 继续优化浏览器和 Clash 高并发场景，重点降低每条连接的建连、线程与内存成本。

## 改进

- 相同 VPN、相同域名的并发 DNS 查询会合并为一次，并使用短时正/负缓存。
- VPN 切换或断开时立即清空 DNS 缓存，避免复用旧网络结果。
- SOCKS5 握手、请求解析和上游连接全部迁移到非阻塞 Selector 状态机。
- TCP Selector lane 根据设备 CPU 核心数动态调整为 2–4 条。
- TCP DirectBuffer 按需申请并复用，空闲连接不再预留 64 KiB 缓冲区。
- 活跃会话改用常数时间计数，状态持久化、LAN 地址刷新和通知栏更新均已节流。

## 真机验证

Pixel 10a、系统 Google VPN、同一 Wi-Fi 客户端：

- 120/120 路突发 SOCKS5 TCP 建连成功。
- 探针期间应用线程峰值为 41 条；v0.1.1 同类探针峰值为 149 条。
- SOCKS5 TCP 出口地址确认经过系统 VPN。
- SOCKS5 UDP DNS 查询返回成功且包含应答。
- 10 MiB 连续下载返回 HTTP 200，平均约 834 KB/s。
