# Gatewave v0.2.2

Gatewave 0.2.2 面向“网页瞬间建立大量连接，同时存在持续下载”的混合负载，增加应用数据面的交互优先和按字节公平调度。

## 主要变化

- 根据活跃连接数动态缩小单连接 Selector 事件预算。
- 每个 TCP 方向前 256 KiB 归入交互流量，获得独立于持续大流的轮次字节池。
- 多个 LAN 客户端在同一 Selector lane 内按类别获得等额字节份额，未用容量下一轮自动回收。
- 活动页新增交互直写量、公平让出、缓冲排队 P50/P95 和重调度 P50/P95。
- 网络诊断报告同步包含上述数据面指标。
- 新增 `tools/benchmark_mixed_load.py`，可复现“网页小请求 + 后台大下载”场景。

## 验证摘要

- 新增 5 项确定性调度测试，覆盖短流边界、动态预算、类别隔离、多客户端公平和预算退还。
- Pixel 10a 多轮混合负载中，小请求全部成功，后台下载持续活动。
- 80 路并发网页尺寸请求连续两轮均 80/80 成功，峰值会话达到 100。
- Gatewave 内部排队 P95 与预算重调度 P95 均为 2.5 ms，负载结束后缓冲排队归零。

公网延迟主要由 VPN 网关、物理距离和服务端状态决定，Release 中的性能数据用于回归对照，不代表固定公网带宽或延迟。
