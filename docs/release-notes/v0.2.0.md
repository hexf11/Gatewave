# Gatewave v0.2.0

Gatewave 0.2.0 重构高并发数据面，目标是在 Pixel 级设备上充分使用系统 VPN 与 Wi-Fi 能力，同时让浏览器突发连接和多设备共享保持稳定。

## 主要变化

- 动态 1024 会话、1024 accept backlog、128 个 UDP 关联，并根据堆、FD 与性能模式自动降级。
- UDP 改为共享 DatagramChannel Selector；TCP/UDP/握手均不再按会话创建常驻线程。
- 多客户端动态公平份额；满载时后到设备可回收占用过量客户端的最旧会话。
- TCP 使用 O(1) 时间轮、8–64 KiB 自适应 DirectBuffer、缓冲池上限、背压和 15 秒半关闭排空。
- IPv4/IPv6 采用 250 ms Happy Eyeballs 竞速，DNS 缓存和地址健康均按 VPN 网络隔离。
- 新增均衡、极速、省电三档模式；极速模式启用 Wi-Fi 低延迟锁，严重温控时自动释放并清理缓冲。
- 增加容量、客户端、DNS、建连延迟、吞吐、UDP 丢弃、公平回收、Selector 与缓冲池指标。
- 诊断报告隐藏 LAN 地址、VPN 网络标识与出口 IP，可直接匿名分享。
- 状态持久化在节流窗口后静默补刷，服务空闲时的最终会话数也能准确落盘。

## Pixel 10a 验证

- 1024/1024 路 SOCKS5 握手保持成功，峰值线程 37 条。
- 500/500 路 TCP 突发建连成功，P50 1153 ms、P95 1655 ms。
- 128/128 个 UDP 关联同时保持成功；UDP NIO 峰值线程 38 条。
- 经 SOCKS5 UDP 完成真实 HTTP/3 QUIC 握手。
- 息屏状态完成 20 MiB 连续传输。
- 均衡/极速/省电 lane 与容量切换、极速 Wi-Fi 低延迟锁、温控释放/恢复通过。
- 1024 会话满载时，第二客户端协商成功且公平回收计数生效。
- Wi-Fi 断开并恢复后，局域网 SOCKS5 TCP 出口重新可用。
