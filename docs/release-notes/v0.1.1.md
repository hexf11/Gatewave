Gatewave 0.1.1 是面向浏览器高并发连接的性能更新。

## 改进

- TCP 转发改为共享 NIO Selector，不再为每个连接方向长期保留阻塞线程。
- SOCKS5 建连线程按突发流量弹性扩展，并在空闲后自动回收。
- 监听等待队列扩大到 256。
- UDP 与 TCP 使用独立工作池，降低互相影响。

## 实测

Pixel 10a 上建立并保持 120 个 SOCKS5 TCP 会话：

- 成功率：120/120。
- 建连 P50：约 0.54 秒。
- 建连 P95：约 1.54 秒。
- 会话稳定后应用线程数：约 37 条。
- 10 MiB 连续下载与 SOCKS5 UDP DNS 检查均通过。
