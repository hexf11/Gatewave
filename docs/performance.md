# Gatewave 性能架构

Gatewave 的数据面只实现 SOCKS5 `CONNECT` 与 `UDP ASSOCIATE`。配置订阅使用 HTTP，但不提供 HTTP 代理协议。

## 容量策略

启动时根据应用最大堆、进程 FD 上限和性能模式计算容量：

| 设备/模式 | 总会话 | UDP 关联 | accept backlog |
| --- | ---: | ---: | ---: |
| Pixel 级 / 均衡 | 1024 | 128 | 1024 |
| Pixel 级 / 极速 | 1024 | 128 | 1024 |
| 省电 | 512 | 64 | 512 |
| 小内存或低 FD | 256–768 | 64–96 | 与总会话一致 |

空闲单客户端可以使用全部总会话。多客户端接近饱和时会启用预留区；满载时，低于动态公平份额的客户端可以从占用过量的客户端回收最旧会话。

## NIO 数据面

- SOCKS5 协商：1–2 条 Selector lane。
- TCP 转发：1–4 条 Selector lane；每个连接只注册两个非阻塞 SocketChannel。
- UDP 转发：1–2 条 Selector lane；每个关联使用客户端侧和 VPN 上游侧两个非阻塞 DatagramChannel。
- VPN DNS：固定 4 条工作线程，支持同域名 single-flight 合并。

因此，保持 1024 个空闲会话或 128 个 UDP 关联不会创建同等数量的线程。

## TCP 内存与生命周期

- 上游 TCP socket 接收窗口按模式请求 512 KiB、2 MiB 或 8 MiB；极速模式的大窗口用于改善高 RTT 路径的窗口爬升。
- DirectBuffer 只在实际读写时获取，空闲连接不预分配转发缓冲。
- 每个方向会根据连续读大小动态增长或收缩；省电、均衡、极速的上限分别是 32、64、128 KiB。
- 每条 lane 的空闲 DirectBuffer 池上限按模式为 1、4、8 MiB；系统低内存或严重温控时立即清空。
- 读取后先在同一个 Selector 就绪事件内直接写入目标端，成功排空时继续批量读取，不再让每个数据块额外等待一次可写事件。
- 每次就绪事件的处理预算按模式限制为 64、256、512 KiB；达到预算后保留读兴趣并让出事件循环，防止大下载饿死小请求。
- 每个方向仅允许一块待写缓冲；目标端未排空前暂停源端读取，形成自然背压。
- SOCKS 请求后已被控制通道预读的首批 TCP payload 会在交接时继续转发，不会因 Selector lane 切换丢失。
- 普通空闲连接 180 秒回收；单侧关闭后保留 15 秒排空窗口。
- 空闲检测使用 256 槽时间轮，调度和移除均为常数时间。

## DNS 与建连

- 正缓存 60 秒、负缓存 5 秒，最多 512 个条目。
- 缓存键包含 Android VPN network handle；VPN 切换后清空全部缓存和地址健康状态。
- IPv4/IPv6 地址按首选地址族交替排列，每 250 ms 启动下一候选连接。
- 失败地址只在当前 VPN 网络中降级；成功后恢复其健康状态。

## UDP 快路径

- 每个 UDP 关联保存最多 256 个目标端点；同一域名/IP 与端口的后续数据报直接复用结果。
- IPv4/IPv6 字面量不进入异步 DNS 调度，缓存命中也不再重复投递 selector 命令。
- SOCKS5 UDP 解码与返回封装各只保留一次 payload 分配，待发送队列复用同一 ByteBuffer。
- 活动日志公开快路径命中、解析次数、队列峰值与丢弃数，便于定位 QUIC/实时流量问题。

## 性能模式

- **均衡**：按 CPU 选择 Selector 数量，TCP 初始/最大转发缓冲 16/64 KiB、单事件预算 256 KiB、上游接收窗口 2 MiB。
- **极速**：4 条 TCP lane、2 条握手/UDP lane、TCP 初始/最大转发缓冲 32/128 KiB、单事件预算 512 KiB、上游接收窗口 8 MiB，并持有 Wi-Fi 低延迟锁。
- **省电**：单 lane、512 总会话、TCP 初始/最大转发缓冲 8/32 KiB、单事件预算 64 KiB、上游接收窗口 512 KiB，不持有 Wi-Fi 性能锁。

Android 报告严重温控状态时，极速模式会释放 Wi-Fi 低延迟锁并清理空闲缓冲；温控恢复后自动重新获取。

## 可观测性

活动日志提供：活跃与峰值会话、活跃客户端、容量、Selector 数、DNS 命中/查询/合并、建连 P50/P95、实时吞吐、TCP 上游窗口、当前/峰值排队、同事件直写量、背压次数、公平让出次数、DirectBuffer 复用/分配、UDP 快路径/解析/队列峰值/丢弃、公平回收、TCP 缓冲池和半关闭排空数。

网络诊断额外执行 VPN TCP RTT、单流与 4 流短下载；高 RTT 且并发收益明显时会标记“高延迟单流受限”。分享文本只包含聚合指标，具体 LAN 地址、VPN 标识与出口 IP 会被隐藏。
